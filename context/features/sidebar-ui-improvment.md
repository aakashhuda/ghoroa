# Sidebar UI Improvement

## Overview

The current sidebar works fine but we would like to make some changes in how it looks. We want to bring a modern and sleek ui which complements our current Dashboard page's colors. Eventualy we'll use this dasboard color pallet in the whole project. So we need to set the the Ant Vue theme colors to our new colors

## Requirements for Sidebar UI Improvement

- Study the @app/components/dashboard/DashboardView.vue for the current color combinations used there.
- Generate theme colors according to the combination you found and also use your UI/UX design skills to set our Ant Vue theme colors
- Apply the theme colors to Ant vue theme so the sidebar reflects the new color combination. The main content of the dashboard page is not going to change a bit as it is already has the colors we want.
- The strucure and functionality of the sidebar will stay the same only the colors will change.
- For making it look matching with the dashboard content make the neccessary subtle changes in our Ant Vue theme.
- If the theme color already represents the dashboard colors perfectly then don't make the changes
