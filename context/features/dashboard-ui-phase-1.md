# Dashboard UI Phase 1 Spec

## Overview

This is phase 1 of 3 for the dashboard UI layout. Use the screenshot referenced below for how it should look.

## Requirements for phase 1

- Ant Vue is already installed
- Use 'Ant Vue' for component library everywhere
- Create directories in pages and components for dashboard.
- Dashboard route at /dashboard
- Create the right layout for the dashboard. (layouts/default.vue)
- Create the Dashboard Page and Component with only the page title
- Top bar with search and a New button with icon which shows a dropwdown of customer, tenant as options to create.
- Placeholder for sidebar and main area. Just add an h2 with "Sidebar" and "Main" for now. No need to design now. Just structure
- Light mode by default
